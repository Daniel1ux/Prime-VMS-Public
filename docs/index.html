Frequently asked questions

Is PrimeVMS really free?

Yes. The VMS core — live view, recording, playback, export, users, distributed servers and updates — is free, with no per-camera license fees. Only the advanced modules (AI analytics, Prime Cloud, high availability) are paid, on affordable plans.

Which cameras are supported?

Any IP camera with ONVIF or RTSP, from any manufacturer. PrimeVMS finds ONVIF cameras on the network and discovers the stream path by itself.

Is it an NVR replacement?

PrimeVMS records IP cameras directly on a Windows PC or server (software NVR), with retention by days, and also works alongside existing recorders that expose RTSP.

How many cameras can I use?

There is no license limit per camera in the free core. The practical limit is your hardware and network; for larger projects, use the distributed installation with several recording servers.

Which languages are available?

English, Portuguese (Brazil) and Spanish — in the apps, the installer and the release notes.
